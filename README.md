# Small World

Ramus lavinamasis nuotykių pasaulis 4–6 metų vaikams.

## MVP tikslas

Pirmu etapu tikriname vieną svarbiausią hipotezę: ar vaikui įdomu mokytis tada, kai teisingas atsakymas fiziškai keičia jo pasaulį.

Pirmas žaidimo ciklas:
1. Meškiukui reikia pastatyti tiltą.
2. Vaikas suskaičiuoja, kiek lentų trūksta.
3. Teisingai pasirinkus, viena tilto dalis atsiranda pasaulyje.
4. Po trijų sėkmingų užduočių tiltas užbaigiamas.
5. Sesija turi aiškią ramią pabaigą.

## Technologijos

- Expo
- React Native
- TypeScript
- Be backend pirmame prototipe

## Paleidimas

```bash
npm install
npx expo start
```

Tada telefone atidarykite Expo Go ir nuskenuokite QR kodą.
